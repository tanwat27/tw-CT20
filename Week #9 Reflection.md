# Week #9 Reflection

## class work

This week we had open work time during class on both tuesday and thursday. I spent that time working on my Recombination project. I'm trying to make a Spotfy Wrapped parody, but with stats from when I had covid in February. The idea is that it would work sort of like a slideshow, with stats, pictures, and animations over 5-10 slides. So far I have been designing each slide, figuring out how I want everything to look, and when I'm done with that, I'll work on figuring out how to call each slide in succession by pressing the arrow keys on the keyboard. If things go well, I might try to add sound, but it's not at the top of my priority list because the project will be mostly visual either way. I think it would be a nice addition if I end up having the time, though.

I've found some helpful YouTube videos that break down different parts of animations in P5.js from the YouTuber Jeff Thompson, covering rotation, position, and other effects. I've also been playing with loading in custom fonts, since a lot of my project is text-based.

I also really enjoyed being in the loud breakout rooms this week, it was cool getting to see what other poeple are working on at the moment and how other students want to give suggestions or edits to someones project! I hope we get to do more of that next quarter.
